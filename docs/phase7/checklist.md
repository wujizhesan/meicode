# MewCode Phase7 Checklist

> 每一项通过运行代码或观察行为来验证，聚焦系统行为。

## 实现完整性

- [ ] 单条存盘（验证：5KB 工具结果 → tool 消息含 `[已存盘]`+预览+路径；artifacts 文件内容完整）
- [ ] 批次存盘（验证：同批 3 结果合计超 8KB → 大的先存盘，剩余合计 ≤8KB）
- [ ] 摘要触发（验证：小窗口配置（3000）逼近 → 早期消息被摘要 system 消息替换）
- [ ] 近期保留（验证：尾部 ≥5 条 / 1 万 token 内原文保留）
- [ ] 摘要请求纯净（验证：fake provider 捕获摘要请求——无 tools 参数）
- [ ] 边界消息（验证：压缩后历史出现「部分早期对话已摘要…」）
- [ ] 手动触发（验证：manager.beforeRequest('manual') 立即压缩，余量 3K）
- [ ] 熔断（验证：摘要连续失败 3 次 → 自动模式不再触发；manual 仍可用；成功清零计数）
- [ ] 用户消息保留（验证：压缩后所有 user role 消息原文存在）

## 集成

- [ ] loop 挂钩（验证：工具结果回灌前 spill 生效；请求前 beforeRequest 被调用）
- [ ] 锚点更新（验证：afterRequest 后估算基于新锚点，不重复计算旧消息）
- [ ] /compact 命令（验证：TUI 输入 /compact 触发手动压缩并提示结果）
- [ ] 回归（验证：P1-P6 全部用例绿）

## 编译与测试

- [ ] `npx tsc --noEmit` exit 0
- [ ] `npm test` 0 failed（98 + 新增全量）

## 端到端场景（真实 DeepSeek，`npm start`）

- [ ] 场景 1 · 存盘：多轮对话让模型读取大文件（如 package-lock.json）→ 回复或 artifacts 目录可见存盘文件
- [ ] 场景 2 · 自动摘要：临时配置 `context_window: 5000` → 多轮对话后早期消息被摘要替换，对话仍正常继续
- [ ] 场景 3 · 手动压缩：`/compact` → 提示压缩完成，早期内容摘要化
- [ ] 场景 4 · 配置还原：context_window 还原默认，长对话无异常
