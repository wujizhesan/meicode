# MewCode Phase5 Spec — 权限系统

## 背景

P1-P4 已交付：对话 → 工具 → Agent Loop → 系统提示工程。当前 run_command 自主执行（P3 移除确认）、文件工具无范围限制。本阶段装五层防御权限系统：黑名单硬拦截、路径沙箱、配置规则、权限模式、人在回路。权限被拒绝时不终止 Agent Loop——结构化结果回灌，让模型调整策略。

## 目标

- 五层裁决链，从硬拦截到人工兜底
- 三层 YAML 规则（用户/项目/本地），越靠近项目优先级越高
- 三档权限模式整体切换，覆盖具体规则
- 人在回路弹窗：本次 / 本会话 / 永久三种放行

## 五层裁决链

```
① 黑名单（硬编码正则，不可配置）→ 拒绝
② 路径沙箱（realpath 解析后校验 cwd 前缀）→ 越界拒绝（规则 allow 可显式放开）
③ 规则逐层裁决（本地级 > 项目级 > 用户级）→ 命中即 allow/deny
④ 未命中 → 按权限模式：strict 拒绝 / default 弹窗 / permissive 放行
⑤ 拒绝/弹窗结果 → 结构化回灌模型，循环继续（不终止）
```

## 功能需求

- F1: 危险命令黑名单 —— run_command 执行前用硬编码正则预检高危命令（删除/格式化/危险递归等模式），命中即拒绝；该层不可被配置放开
- F2: 路径沙箱 —— read_file/write_file/edit_file 的目标路径先 `realpath` 解析（防符号链接逃逸）再做 cwd 前缀判断；越界默认拒绝，规则中显式 allow 可放开
- F3: 三层规则 —— 用户级 `~/.mewcode/rules.yaml`、项目级 `<cwd>/.mewcode/rules.yaml`、本地级 `<cwd>/.mewcode/rules.local.yaml`；格式「工具名(模式)」：`run_command(git *)`、`read_file(src/**)`；结果仅 allow/deny；参数/路径模式支持精确与 glob 匹配
- F4: 权限模式 —— strict（白名单制：规则明确 allow 才放行，其余拒绝不弹窗）/ default（规则裁决 + 未命中弹窗）/ permissive（仅黑名单与沙箱拦截，其余放行）；模式通过 YAML 配置与 TUI 命令 `/mode` 切换
- F5: 人在回路 —— default 模式规则未命中时弹窗：Enter=本次放行、S=本会话放行（写入内存会话级临时规则）、P=永久放行（写入项目级 rules.yaml）、Esc=拒绝；本次/会话放行即时生效
- F6: 规则优先级 —— 会话级临时规则 > 本地级 > 项目级 > 用户级；同一工具同层多条规则：deny 优先于 allow（安全惯例）
- F7: 拒绝不终止 —— 任何层拒绝都返回结构化结果（`[权限拒绝] 原因 + 建议调整方向`）回灌模型，Agent Loop 继续

## 非功能需求

- N1: 规则文件加载失败（YAML 解析错误）→ 提示警告并跳过该层，不崩溃
- N2: 黑名单不可配置（代码内置，无配置入口）
- N3: 弹窗为模态交互：弹窗期间输入框禁用（复用 P2 确认弹窗模式）
- N4: 权限裁决不引入额外网络请求（纯本地）

## 不做的事

- 网络请求限制（URL 过滤）
- 资源配额（token/时间/文件大小限额）
- 审计日志（记录全部权限事件）
- 远程策略分发

## 验收标准

- AC1: 黑名单 —— 构造高危命令（`rm -rf /` 类）→ 执行前被拒，错误含「黑名单」；无可配置入口
- AC2: 沙箱 —— 指向 cwd 内符号链接到外部文件的路径 → 被拒（realpath 后越界）；cwd 内正常读写不受影响
- AC3: 规则裁决 —— `run_command(git *)` allow 放行 git 命令、deny 拦截指定命令；`read_file(src/**)` glob 匹配
- AC4: 三层优先级 —— 同工具同名模式，本地 deny / 项目 allow / 用户 allow → 本地 deny 生效
- AC5: 模式 —— strict 下未 allow 即拒（不弹窗）；permissive 下仅黑名单拦截；default 下未命中弹窗
- AC6: 人在回路 —— default 未命中弹窗：本次放行生效一次、会话放行持续、永久放行写入项目级文件、Esc 拒绝；拒绝后 fake 验证循环继续且模型收到结构化拒绝
- AC7: 回归 —— P1-P4 全部测试通过（62 项 + 新增）
