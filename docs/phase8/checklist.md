# MewCode Phase8 Checklist

> 每一项通过运行代码或观察行为来验证，聚焦系统行为。

## 实现完整性

- [ ] 指令三层加载与优先级（验证：项目根内容拼接在最前，用户级最后；缺层跳过）
- [ ] @include 三防（验证：A↔B 互引不无限递归；深度 >5 截断；`../../` 越界路径跳过并提示）
- [ ] 会话 JSONL 追加写（验证：append 后文件行数 = 消息数，每行可 parse）
- [ ] 恢复处理（验证：坏行跳过；assistant(tool_calls) 无 tool 结果 → 截断；最后消息 >24h → 插入时间提醒）
- [ ] 30 天清理（验证：伪造旧 mtime 文件被删，新文件保留）
- [ ] 自动笔记（验证：fake LLM 返回 JSON → frontmatter 文件创建；action=update 同名更新不新增；坏 JSON 静默）
- [ ] 索引（验证：格式 `- [category] title — 摘要`；>25KB 截断）

## 集成

- [ ] 启动恢复（验证：存在会话文件时启动提示「已恢复会话 <id>（N 条消息）」且历史可用）
- [ ] send 后存档（验证：一轮对话后 JSONL 出现新消息行）
- [ ] 注入（验证：请求 system 含「## 项目指令」与「## 记忆索引」段）
- [ ] 异步笔记（验证：done 自然停后触发 updateNotes 且不阻塞对话；调用失败无异常上抛）
- [ ] 回归（验证：P1-P7 全部用例绿）

## 编译与测试

- [ ] `npx tsc --noEmit` exit 0
- [ ] `npm test` 0 failed（113 + 新增全量）

## 端到端场景（真实 DeepSeek，`npm start`）

- [ ] 场景 1 · 指令：项目根写 `instructions.md`（如「技术栈：TypeScript + Node 24」）→ 重启问「项目用什么技术栈」→ 模型答出
- [ ] 场景 2 · 恢复：对话几轮 → 重启 → 提示恢复会话且历史在（问「我上轮问的什么」能答）
- [ ] 场景 3 · 笔记：多轮自然停后 → `.mewcode/memory/` 出现笔记文件与 index.md，重启后模型能引用（索引注入生效）
- [ ] 场景 4 · 清理：手动造一个 31 天前的会话文件 → 重启 → 提示已清理
