# MewCode Phase8 Spec — 记忆系统

## 背景

P1-P7 已交付完整 Agent，但每次启动都失忆。本阶段装三套机制：项目指令文件（知识注入）、会话存档（中断续接）、自动笔记（长期记忆），实现工作记忆与长期记忆分层管理。

## 目标

- 启动自动恢复最近会话，中断后平滑续接
- 项目/用户指令文件多层加载，模型优先遵循
- 每轮自然停后异步更新自动笔记，Agent 越用越懂用户

## 功能需求

- F1: 项目指令文件 —— 三层手写 Markdown：用户级 `~/.mewcode/instructions.md`、项目级 `<cwd>/.mewcode/instructions.md`、项目根 `./instructions.md`；按优先级拼接（高优先级在前，用户级最低）；支持 `@include <path>` 引用其他文件——嵌套深度限 5 层、visited 集合防环路、拦截跳出项目目录的路径（越界跳过并提示）
- F2: 会话存档 —— `sessions` 目录（项目级 `<cwd>/.mewcode/sessions/`）每个会话一个 JSONL 文件（消息逐条追加写）；会话 ID `YYYYMMDD-HHMMSS-xxxx`（时间戳 + 4 位随机防同秒撞车）；不维护 meta 文件——会话 ID/标题/消息数需要时直接扫 JSONL 计算
- F3: 会话恢复 —— 启动自动恢复最近会话（显示会话 ID 与消息数）；恢复时：坏行跳过、工具调用无对应结果时截断该轮、token 估算超限先做一次上下文压缩（P7 机制）、距上次活动超过 24 小时插入时间跨度提醒消息
- F4: 过期清理 —— 启动时扫描 sessions 目录，删除 30 天前最后活动的会话文件（日志提示）
- F5: 自动笔记 —— 四类：user_pref（用户偏好）/ correction（纠正反馈）/ project_knowledge（项目知识）/ reference（参考资料）；每轮 Agent 自然停后（最终回复无工具调用）**后台异步**调 LLM 更新（不阻塞 UI）；去重由 LLM 判断（已有则更新原笔记）；用户级 `~/.mewcode/memory/` 与项目级 `<cwd>/.mewcode/memory/` 分开存；每条笔记一个带 frontmatter（类别/时间/标题）的 Markdown 文件
- F6: 记忆索引 —— 请求前把笔记索引（类别+标题+摘要行）拼进主 system prompt 尾部（模型直接看到，相当于已读过）；索引文件控制在 200 行 / 25KB 以内（超限截断）

## 非功能需求

- N1: 崩溃安全 —— JSONL 追加写崩溃只丢最后一行，恢复可跳过坏行
- N2: 异步笔记不阻塞对话（后台执行，失败静默不影响主流程）
- N3: 索引硬上限 25KB（超限截断并标注）

## 不做的事

- 向量数据库 / RAG 检索
- 团队记忆同步
- 笔记去重的向量相似度计算（LLM 判断即可）

## 验收标准

- AC1: 指令三层加载 + 优先级拼接（用户级在前还是后——高优先级在前）+ `@include` 的环/深度/越界拦截
- AC2: 会话 JSONL 追加写与恢复：坏行跳过、工具调用无结果截断、>24h 时间提醒
- AC3: 启动自动恢复最近会话（ID/消息数显示）
- AC4: 30 天前会话启动时被清理
- AC5: 自动笔记：fake LLM 断言——自然停后触发、分类正确、去重更新而非重复新增、异步不阻塞
- AC6: 索引拼进主 system 尾部且 ≤25KB（超限截断）
- AC7: 回归 —— 全部现有测试绿

## 文件组织约定

```
<项目>/
├── instructions.md              — 项目指令（最高优先级）
├── .mewcode/
│   ├── instructions.md          — 项目级指令（次高）
│   ├── sessions/
│   │   └── 20260809-103000-abcd.jsonl
│   ├── memory/
│   │   ├── index.md             — 项目笔记索引
│   │   └── 20260809-<slug>.md   — 项目笔记
│   └── artifacts/               — P7 存盘（已有）
~/.mewcode/
├── instructions.md              — 用户指令（最低优先级）
├── memory/
│   ├── index.md                 — 用户笔记索引
│   └── 20260809-<slug>.md       — 用户笔记
└── config.yaml / rules.yaml     — 已有
```
