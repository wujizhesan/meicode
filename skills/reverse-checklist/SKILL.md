# 逆向检查清单

> 数据源:reverse-experience-handbook（14 项目成功经验 + 41 篇教训转正向）。
> 用法:每环节开工前过对应门禁,不满足不动手;与角色 SOP 冲突时以更严格者为准。

## A 侦察门
- [ ] A1 形态识别三步:装产品(或找已装)→ ls 探索真实目录 → 识别壳 vs 真身
- [ ] A2 先看原版构建产物(ls build/ 数 HTML)再动键盘
- [ ] A3 参考目标身份要进程级证据(curl title + 端口 + 浏览器确认)
- [ ] A4 第一反应是"真实数据长什么样":≥5 样本 → 统计分布表 → 按频实现
- [ ] A5 采集前验证数据非空(curl ≥3 端点),空数据报错退出
- [ ] A6 选管线前比较所有候选版本产出质量
- [ ] A7 大文件策略性阅读:grep 关键词 → 偏移精读 → 计数判断权重
- [ ] A8 先评估混淆程度再选路径(可读直接 grep,省 webcrack)

## B 提取门
- [ ] B1 内嵌 bundle 用 dd_extract 按字节偏移提取
- [ ] B2 extract_strings 当一等工具(filter/偏移/最长优先)
- [ ] B3 VNode→模板必须 AST,正则 90 倍差距
- [ ] B4 嵌套 template 用深度计数提取
- [ ] B5 render 提取覆盖 5 种嵌入模式(内联/wrapper/Kt 包装/懒加载/纯逻辑跳过)
- [ ] B6 VNode 别名自动检测不硬编码
- [ ] B7 别名映射用属性使用验证方向(有 .push 是 router,有 .params 是 route)
- [ ] B8 修 HTML/CSS 先找现成库(html5lib > BS4,BS4 禁用于 .vue)

## C 转换/管线门
- [ ] C1 四步法不可跳步(侦察 5min+统计 5min 防 2-8h 修补)
- [ ] C2 ≥3 文件必须管线化(3 是硬线)
- [ ] C3 手工修复立刻写回管线重新生成(N× 成本 vs 脚本≈0)
- [ ] C4 同类错误 ≥3 追踪生成点(后处理 9 倍代价)
- [ ] C5 管线产物不符先审 pass/TODO(几乎总是核心步骤没实现)
- [ ] C6 融合优于完美(两条半吊子互补 > 死磕一条)
- [ ] C7 94% 手动精修截止线(边际成本急剧上升)
- [ ] C8 ESCodegen 整函数体重生禁止(只做定向节点替换)
- [ ] C9 压缩名替换必须 \b 词边界(round→rounref 静默错)
- [ ] C10 Vue 3 映射陷阱清单(7 项:reactive 只接对象/剥 .value/显式闭合等)
- [ ] C11 安全后处理只做验证过的 5 项最小修复
- [ ] C12 字典 merge 前查同名 key({**a,**b} 无声覆盖)
- [ ] C13 管线跨阶段交叉验证(API 名称漂移)
- [ ] C14 别名注入四规则(逗号链后/AST 分析/内置不注入/多模式)
- [ ] C15 管理后台 5+ 同构页用配置驱动生成器(10 倍效率)
- [ ] C16 递进校准不跳级

## D 验证门
- [ ] D1 验证门 = 报错检查 + 结构对比(tag 数/class/文本片段)
- [ ] D2 像素对比前关非确定性元素(canvas 动画 77.7%→0.04%)
- [ ] D3 一模一样 = DOM 树逐层一致
- [ ] D4 融合产出必须连原版后端 live 对比(<5%)
- [ ] D5 像素天花板按模式区分(v-html 可追 0.04%,SFC 不追 30%)
- [ ] D6 模板神圣不可侵犯(CDP 捕获的 DOM 是唯一真理)
- [ ] D7 证据驱动报告(结论带 文件:行号/偏移 + 未确认项)
- [ ] D8 汇报先报覆盖率(X/N,不包装概念验证)
- [ ] D9 单文件 Edit >5 次就整文件重写

## E 协作门
- [ ] E1 recon→replicator→verifier 流水线(产出物契约)
- [ ] E2 GUI 自动化工具优先级(MCP > 自写 CDP)
- [ ] E3 按需工具替代全局安装(npx -y)
- [ ] E4 Electron 双模式三件套(main+preload+electronAPI)
- [ ] E5 Electron 4 预案(CDP 先看 target URL/两步 build/electron-rebuild)
- [ ] E6 品牌替换 7 步(fork→替换→包名→样本→断言→rebuild→appid)
- [ ] E7 模糊不满意先问维度再改(猜着改慢 10 倍)
- [ ] E8 记忆按场景分写,但必须有执行机制(清单/hooks/三问)
- [ ] E9 bash 内联多行必写文件执行
- [ ] E10 含中文文件 Read+Write 全文件

## F 止损门
- [ ] F1 反爬按现象分级定性(403/429→验证码→指纹→签名→302)
- [ ] F2 3 次不通 = 行业级问题,给方案选项让用户选
- [ ] F3 Pre-flight/Post-flight 强制门(自动化脚本)
- [ ] F4 杀进程用 pkill -f <具体名>,绝不 taskkill node.exe
- [ ] F5 三问在出手前强制执行且输出到终端
